## 使用与复核

磁盘安装更新后，运行中的 Pi 执行 `/reload`（或启动新会话），再执行 `/azure-compat status`。升级不会主动发起模型请求；既有持久化的拒绝 ID、clean-next 和分支开关兼容。

0.2.1 的自动修复额度按连续失败链计算。正常完成的主模型响应包含 toolUse 时也刷新；连续错误或部分输出后失败继续共享一次额度。`recoveries` 表示准备次数，不表示服务端成功次数。

本机原始输出留在不纳入 Git 的 `docs/.temp/`：`publish-0.2.1-check.txt`、`publish-0.2.1-installed-check.txt`、`publish-0.2.1-installed-manifest.jsonl`、`publish-0.2.1-installed-retry.jsonl`、`publish-0.2.1-installed-reported.jsonl`。正式方法、结论与限制已在本记录保留。
